Lýsing á verkefni

Í þessu verkefni átti að hanna vefsíðu. Tilgangur vefsíðunnar er að búa til vettvang til að sýna þau verkefni sem ég mun vinna að í áfanganum Tölvustudd framleiðsla. Einnig verður síðan notuð til að birta gagnlegar upplýsingar um mig og minn feril til þessa.

Hönnun síðunar

Til að byrja með hafði ég litla þekkingu á því hvernig ætti að hanna vefsíðu. Hins vegar hafði ég kynnst HTML-skrám í RStudio úr áfanganum Líkindi og tölfræði.

Eftir að horfa á myndböndin fyrir verkefni 1 valdi ég mér uppsetninguna LANDED frá html5up.net, sem mér leist mjög vel á. Ég hlóð henni niður í Visual Studio Code og byrjaði að prófa mig áfram. Hægt og rólega aðlagaði ég síðuna síðan að mínum þörfum.

Github

Til að setja síðuna á netið notaðist ég við Github.com. Eftir að hafa stofnað aðgang bjó ég til repository

    Eftir að repository var klárt valdi ég að hlaða upp tilbúnum skrám. Ég afritaði síðan allar skrárnar úr möppunni minni inn á GitHub og þá var síðan komin í loftið.

    Framtíðar uppfærslur

    Það eru nokkrar leiðir til að uppfæra breytingar á síðunni

  • Breyta kóðanum á github.
  • Breyta honum í VS code eða öðrum svipuðum forritum og notast við Git.
  • Hlaða upp uppfærðum skrám.

Ég mun persónulega notast við Git til að uppfæra nema ef um litlar breytingar er að ræða en þá uppfæri ég beint inná Github vafranum.

Útkoman

Útkoma vefsíðunar var miklu betri en ég bjóst við en það koma á óvart hversu vel gekk að koma vefsíðunni í loftið með Github. Ég prófaði nokkrar aðrar litabreytingar en fann ekki neina flottari en sem var nú þegar. Einnig hefur þetta verkefni opnað nýjan möguleika fyrir mig en fyrir þetta verkefni hafði ég aldrei gert vefsíðu áður eða notað Github.
